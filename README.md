# spacetime_build

本项目用于在不修改旧构建工具的前提下，重新实现 SE 项目的 Unity 构建系统。工程采用
Python 3.10+ 和 `src` 布局，顶级导入命名空间为 `st.build`。

当前仅完成第一阶段的基础工程骨架：包导入入口、版本标识，以及 pytest、Ruff、Pyright
等质量工具配置。领域模型、任务 DAG、旧客户端协议、资源构建和发布能力仍在规划中，
尚不可用。
