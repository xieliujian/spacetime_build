> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在第二阶段 Release 领域模型稳定后，以字节级 Golden 测试实现旧客户端六字段文件列表和 `assetbundledb_*.txt` 的 DTO、writer、parser，并预留可审计的旧客户端解析验证证据。

**Tech Stack:** Python 3.10+、不可变 dataclasses、enum、UTF-8、pytest、pytest-cov、Ruff、Pyright。

**设计文档:** `readme/version_build/00_全新构建系统设计.md` 第 8 节。
