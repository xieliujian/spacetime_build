**Goal:** 为进程、隔离工作区、SVN、Unity、Jenkins、对象存储/CDN 和凭据建立稳定端口与可测试适配器。

## 3. 公共契约

```python
@dataclass(frozen=True, slots=True)
class ProcessRequest:
    executable: Path
    arguments: tuple[str, ...]
    working_directory: Path
    timeout_seconds: int
    environment: tuple[tuple[str, str], ...]
    redacted_argument_indexes: frozenset[int]
    secret_bindings: tuple[SecretProcessBinding, ...]

class ProcessRunner(Protocol):
    def run(
        self,
        request: ProcessRequest,
        cancellation: CancellationToken,
        secret_lease: SecretLease | None = None,
    ) -> ProcessResult: ...

class HttpTransport(Protocol):
    def send(
        self,
        request: HttpRequest,
        cancellation: CancellationToken,
        secret_lease: SecretLease | None = None,
    ) -> HttpResponse: ...

class SecretProvider(Protocol):
    def acquire(
        self,
        request: SecretLeaseRequest,
        cancellation: CancellationToken,
    ) -> SecretLease: ...

class SecretLease(Protocol):
    @property
    def binding_ids(self) -> tuple[str, ...]: ...
    @property
    def public_fingerprints(self) -> tuple[str, ...]: ...
    def close(self) -> None: ...

class SourceProvider(Protocol):
    def resolve_revision(self, source: SourceRef) -> ResolvedSource: ...
    def materialize(self, source: ResolvedSource, destination: Path) -> SourceSnapshot: ...

class SourceRepositoryAdmin(Protocol):
    def inspect(self, request: SourceAdminInspectRequest) -> SourceAdminSnapshot: ...
    def apply(self, request: SourceMutationBatch) -> SourceMutationResult: ...
    def relocate(
        self,
        request: SourceRelocateRequest,
        cancellation: CancellationToken,
    ) -> SourceRelocateResult: ...

class CiJobClient(Protocol):
    def trigger(self, request: CiJobRequest) -> CiJobHandle: ...
    def get_status(self, handle: CiJobHandle) -> CiJobStatus: ...
    def cancel(self, request: CiCancelRequest) -> CiCancelResult: ...

class ObjectStore(Protocol):
    def put(self, request: PutObjectRequest) -> StoredObject: ...
    def verify(self, reference: StoredObject) -> ObjectVerification: ...
    def compare_and_swap(self, request: CompareAndSwapRequest) -> CompareAndSwapResult: ...
```

`SecretLeaseRequest` 只声明 SecretRef、用途、允许的进程/HTTP 绑定方式、受控临时材料策略和过期时间；
`SecretLease` 只暴露不透明 binding ID 与公开指纹，不暴露明文字节。ProcessRunner 在创建子进程前
按 binding ID 将秘密绑定到标准输入、受限临时文件或指定环境键；HttpTransport 在发送前按
`SecretHttpBinding` 将秘密绑定到白名单 Authorization/header、客户端证书或请求签名槽位。两种 transport
都保证 argv/request repr/日志脱敏，Jenkins/ObjectStore 适配器只能传 opaque binding ID，不能读取明文；
成功、失败、超时和取消都必须在 `finally` 关闭租约、销毁临时材料。禁止在适配器构造时长期解析秘密。

`SourceRepositoryAdmin` 仅供计划 29 的显式分支变更使用，默认不绑定生产凭据。mutation batch
必须携带固定仓库 revision、唯一幂等键和同仓库原子操作集合；禁止覆盖已存在目标或接受任意
svn 子命令。`relocate` 只接受 WorkspaceLease 内已验证 working-copy root、仓库 UUID 和精确 URL
对，不能复用服务器 mutation batch，也不能扫描租约外目录。所有请求必须在调用适配器前完成
路径、整数、URL、revision 和凭据引用校验。

## 4. 数据流与运行约束

```text
application request
  -> validated port DTO + SecretRef
  -> integration adapter
  -> ProcessRunner / HTTP transport
  -> bounded raw output
  -> typed result or typed BuildError
  -> redacted audit summary
```

| 能力 | 幂等与并发 | 重试/取消 | 缓存 |
| --- | --- | --- | --- |
| Process | 单 request 只执行一次；进程组隔离 | 超时/取消终止进程树，不自动重试 | 不适用 |
| Workspace | build ID 单租约；根目录内互斥 | 取消后按策略保留诊断 | 不缓存工作区 |
| SVN | 固定 revision materialize 可重放 | 认证/语法错误不重试，临时网络错误有限重试 | 只缓存不可变快照 |
| Unity | workspace 与许可证键互斥 | 工具失败不重跑全流水线 | Task 层决定产物缓存 |
| Jenkins | idempotency key 防重复触发 | 临时 HTTP 错误有限重试，可取消轮询 | 不缓存状态 |
| Object store | 内容键 put 幂等；CAS 串行化入口 | 上传可重试，CAS 冲突不重试 | Blob 本身不可变 |

失败统一记录适配器名、请求摘要、退出码/HTTP 状态、日志 locator 和重试次数；不得记录 secret value。

## 6. 失败排查与证据

| 症状 | 排查入口 |
| --- | --- |
| 子进程未退出 | ProcessResult、进程组 ID、取消时间线 |
| 工作区污染 | WorkspaceLease、解析后的根路径、保留策略 |
| revision 漂移 | ResolvedSource 与 SourceSnapshot 摘要 |
| Unity 无输出 | UnityBatchRequest、退出码、日志 locator、expected roots |
| Jenkins 重复任务 | idempotency key、queue/build ID |
| CAS 冲突 | expected/current generation 和目标对象键 |

自动化证据记录到 `readme/evidence/integrations/自动化门禁.md`；真实环境探针记录到 `readme/evidence/integrations/外部系统探针.md`。证据缺失时保持对应平台状态未验收。
