# 第三阶段兼容协议 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在第二阶段 Release 领域模型稳定后，以字节级 Golden 测试实现旧客户端六字段文件列表和 `assetbundledb_*.txt` 的 DTO、writer、parser，并预留可审计的旧客户端解析验证证据。

**Architecture:** compatibility 只负责从 `ReleaseEntry`/`ReleaseManifest` 转换文件列表 DTO、从已验证 `ReleaseSnapshot` 转换 AB DTO，并编解码旧文本协议，不重新定义构建或发布领域模型。DTO、writer、parser、换行策略分别拆文件；AB DTO 不提供任意公开构造入口，排序只使用 UTF-8 字节键，依赖 tuple 严格保序保重复。

**Tech Stack:** Python 3.10+、不可变 dataclasses、enum、UTF-8、pytest、pytest-cov、Ruff、Pyright。

**设计文档:** `readme/00_全新构建系统设计.md` 第 8 节。
