# 正式版本制作资料

本目录用于记录正式版本资源构建、版本生成、聚合和发布的设计与后续实施计划。

它与 `readme/version_build/` 的边界如下：

- `version_build` 保存全系统架构、阶段路线图和各基础子系统设计；
- `release_build` 保存一次正式版本制作所需的端到端业务规格；
- 基础领域约束仍以 `version_build/00_全新构建系统设计.md` 为准；
- 当前正式版本制作范围以本目录中的已批准规格为准。
