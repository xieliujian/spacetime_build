## 2. 已实现范围

### 2.1 端口层

- `ports.http`：HTTP 方法、请求/响应、响应大小上限和 Authorization/header binding；
- `ports.secrets`：`SecretLeaseRequest`、`SecretLease`、`SecretProvider`；
- `ports.workspace`：隔离工作区请求和租约；
- `ports.source`：固定 revision、源码身份和树摘要；
- `ports.unity`：结构化 Unity batchmode 请求和结果；
- `ports.ci`：Jenkins Job、队列/构建句柄和状态；
- `ports.storage`：不可变对象、校验和版本入口 CAS；
- 现有 `ports.process` 已支持秘密绑定到 argv、环境、stdin 和受控临时文件，租约在所有
  运行路径关闭，外部输出使用租约值继续脱敏。

### 2.2 适配器层

- `LocalWorkspaceProvider`：build ID 独占工作区、成功清理、失败保留策略；
- `EnvironmentSecretProvider`、`ControlledFileSecretProvider`：短期租约和关闭清理；
- `FileSystemObjectStore`：排他不可变对象、回读摘要、进程内 CAS 和 generation 持久文件；
- `SvnSourceProvider`：受控 `svn info --xml`/`export` 读取、HEAD 固定 revision、确定性树摘要；
  `source_credential` 只在单次命令租约内绑定到脱敏的 `--password` 参数，`info` 与 `export`
  各自申请并关闭独立租约；
- `UnityBatchRunner`：固定 batchmode 参数序列、退出码和预期输出检查；
- `JenkinsJobClient`：触发、队列/build 状态转换和取消；
- `UrllibHttpTransport`：白名单秘密 binding、响应大小限制和租约 finally 清理；
- `IntegrationFactory`：集中组合本地工作区、HTTP、凭据和对象存储实现；在显式提供 SVN
  可执行文件、临时根和 `source_credential` 时额外装配 `SvnSourceProvider`，不在默认 CLI
  中猜测或解析凭据。
